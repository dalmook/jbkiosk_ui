# 점핑배틀 키오스크 UI 비교

현재 화면의 시작 구조와 개선안 4종을 실제로 눌러보며 비교하는 단일 HTML 프로토타입입니다.

## 바로 보기

- GitHub Pages: https://dalmook.github.io/jbkiosk_ui/
- Pages가 아직 준비 중이면 HTML Preview: https://htmlpreview.github.io/?https://github.com/dalmook/jbkiosk_ui/blob/main/index.html

## 비교 시안

- 현재 UI: 회원·비회원·예약 확인을 먼저 선택
- A 속도형: 예약 이용과 현장 이용을 먼저 분리 — 운영 추천
- B 안내형: 한 화면에서 질문 하나씩 진행
- C 현황형: 실시간 방 상태를 첫 화면에 표시
- D 가족형: 가족·친구·생일·단체 구성부터 선택

## 구현된 체험 흐름

시안 선택 → 이용 구분 → 인원 → 방과 시간 → 난이도 9종 → 최종 확인 → 완료

현재는 UI 선택을 위한 프런트엔드 프로토타입이며 실제 예약, 결제, 회원, 방 제어 API에는 연결되지 않았습니다.
